04

Tool-call sequence

The LLM picks a tool; the registry returns facts. Training data never answers.

tool_call_flow.mmd
sequenceDiagram
    autonumber
    actor U as User/Agent
    participant LLM as Local LLM
(Qwen/Gemma)
    participant TR as Tool Registry
    participant KG as Knowledge Graph
    participant DB as Database/API

    U->>LLM: Query + tool descriptions
    LLM->>LLM: Decides which tool to call
    LLM->>TR: function_call(tool_name, params)

    alt KG tool
        TR->>KG: SPARQL query
        KG-->>TR: Structured result
    else External API tool
        TR->>DB: API call
        DB-->>TR: Structured result
    end

    TR-->>LLM: Pydantic-validated result
    LLM->>LLM: Formats response with citations
    LLM-->>U: Structured response

    Note over U,DB: LLM never produces facts from training data
Tools are the source of truth
05

APH approval workflow

Portal states from draft through SC, EVC, SHC, EC, appeal, and LoA.

system_overview.html §7
stateDiagram-v2
    direction TB
    [*] --> DraftApplication
    DraftApplication --> TerCharged : payment via portal
    TerCharged --> DscValidated : DSC verification on all docs
    DscValidated --> DraftApplication : DSC invalid / doc missing
    DscValidated --> ApplicationSubmitted : final submit
    ApplicationSubmitted --> SelfDisclosureIssued : type = EoA Self-Disclosure
    ApplicationSubmitted --> ScrutinyScheduled : type routed via Table 2.3
    ScrutinyScheduled --> ScrutinyCompleted
    ScrutinyCompleted --> ReScrutinyScheduled : deficiencies raised
    ReScrutinyScheduled --> ScrutinyCompleted
    ScrutinyCompleted --> EvcScheduled : EVC required by Table 2.3
    ScrutinyCompleted --> EcQueued : no EVC required
    EvcScheduled --> EvcCompleted
    EvcCompleted --> ShcQueued : deficiencies or SHC required
    ShcQueued --> EcQueued : SHC recommendation
    EcQueued --> LoaIssued : EC approves
    EcQueued --> LodIssued : EC finds deficiencies
    EcQueued --> LorIssued : EC rejects
    LodIssued --> DraftApplication : institution complies within window
    LorIssued --> SacAppealFiled : appeal within 7 days
    LoaIssued --> SacAppealFiled : appeal within 7 days
    SacAppealFiled --> SacHearing
    SacHearing --> EcQueued : SAC recommends fresh SC/EVC
    SacHearing --> LoaIssued : SAC recommends approval
    SacHearing --> LorIssued : SAC concurs with rejection
    LoaIssued --> SecurityDeposited : new institution, §1.12
    SecurityDeposited --> [*]
    LoaIssued --> [*]
    LorIssued --> [*]
    SelfDisclosureIssued --> [*]
