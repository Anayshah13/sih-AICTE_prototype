stateDiagram-v2
    direction LR
    [*] --> ApplicationSubmitted
    ApplicationSubmitted --> DocumentVerifier
    DocumentVerifier --> DeficiencyNotice : verification fails
    DocumentVerifier --> ComplianceChecker : success
    ComplianceChecker --> DeficiencyList : non-compliant
    ComplianceChecker --> FraudDetector : compliant or fixable
    FraudDetector --> ManualReview : high risk
    FraudDetector --> SensorDeploy : needs dimension tracking
    FraudDetector --> EVCVideoAnalyst : low risk
    SensorDeploy --> EVCVideoAnalyst : 30-day data collected
    EVCVideoAnalyst --> PhysicalEVC : anomalies detected
    EVCVideoAnalyst --> ResourceAllocator : clean or verified
    ResourceAllocator --> FinalRecommendation : evaluators assigned
    FinalRecommendation --> HumanOfficerReview
    HumanOfficerReview --> OverrideLogged : officer overrides
    HumanOfficerReview --> DecisionAnchored : officer accepts
    OverrideLogged --> EventEmitted
    DecisionAnchored --> EventEmitted
    EventEmitted --> [*]
    DeficiencyNotice --> [*]
    DeficiencyList --> [*]
    ManualReview --> [*]
    PhysicalEVC --> [*]

sequenceDiagram
    autonumber
    actor U as User/Agent
    participant LLM as Local LLM
(Qwen/Gemma)
    participant TR as Tool Registry
    participant KG as Knowledge Graph
    participant DB as Database/API

    U->>LLM: Query + tool descriptions
    LLM->>LLM: Decides which tool to call
    LLM->>TR: function_call(tool_name, params)

    alt KG tool
        TR->>KG: SPARQL query
        KG-->>TR: Structured result
    else External API tool
        TR->>DB: API call
        DB-->>TR: Structured result
    end

    TR-->>LLM: Pydantic-validated result
    LLM->>LLM: Formats response with citations
    LLM-->>U: Structured response

    Note over U,DB: LLM never produces facts from training data
Tools are the source of truth
